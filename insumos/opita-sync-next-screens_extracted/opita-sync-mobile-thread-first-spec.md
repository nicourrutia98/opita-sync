# Opita Sync — Mobile thread-first (requester)

## Objetivo
Mantener el hilo como vista principal en móvil y mover contexto, formulario y límites del rol a un bottom sheet secundario.

## Estados incluidos
1. Thread principal con composer y acceso a contexto
2. Contexto del caso abierto en bottom sheet

## Componentes visibles
- Header compacto de caso
- Mensajes Usuario / Asistente / Herramienta / Sistema
- Banner de contexto faltante
- Composer principal
- Bottom sheet con estado, próximos pasos, formulario guiado y límites del rol

## Accesibilidad visible
- CTA principal con foco fuerte
- Labels persistentes
- Targets táctiles amplios
- Contraste alto
- Separación clara entre contenido primario y secundario
