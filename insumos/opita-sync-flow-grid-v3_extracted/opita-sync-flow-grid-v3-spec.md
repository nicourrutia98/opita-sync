# Opita Sync — Flow Grid v3

## Direction
Flow Grid v3 is the production-ready lockup for **Opita Sync** under the **Operational Clarity** visual direction.

It is designed for a governed operational platform rather than a generic chatbot. The mark uses a restrained 2×2 grid with one active teal node, three structural dark nodes, and one outlined support node. The result suggests orchestrated flow, governed state, and operational structure without looking playful or futuristic.

## Core palette
- Ink Slate: `#0B1530`
- Support Slate: `#64748B`
- Teal: `#0F766E`
- Mist background: `#F5F7F7`
- Dark solid surface: `#0B2131`

## Construction
- 2×2 grid logic
- top and right connectors use the primary structure color
- left and bottom connectors use the support structure color
- top-right node is teal to signal active synchronization
- lower-left node remains outlined to preserve the “governed flow” character of the mark

## Clear space
Use **x = one node width** around the full primary lockup.

Practical rule:
- primary lockup: keep at least **1x** clear space on every side
- standalone mark: keep at least **0.75x** clear space
- app tile: the icon is already padded for launcher use

## Minimum sizes
- Primary horizontal logo:
  - recommended minimum: **28 px** height
  - dense UI absolute minimum: **24 px** height
- Standalone mark:
  - recommended minimum: **20 px**
  - absolute minimum: **16 px**
- Favicon:
  - use the included favicon-specific export set rather than downscaling the general mark manually

## Background usage
Preferred:
- white
- very light neutral product surfaces
- the included mist background

Allowed:
- solid dark surfaces using the monochrome light variant

Avoid:
- gradients
- glow
- glassy effects
- low-contrast tinted surfaces
- decorative outlines not already part of the mark
- placing the full-color logo over busy imagery

## Accessibility notes
- High-contrast wordmark on light product surfaces
- Calm, restrained color use
- Distinct mark silhouette at small sizes
- Dark and light monochrome variants included for predictable contrast handling

## Production notes
- SVG is the preferred production format for product UI, auth, docs, and design source use.
- PNG exports are included for launcher, favicon, and fallback workflows.
- The horizontal logo asset uses **outlined vector wordmark paths**, so it does not depend on an external font at runtime.

## Recommended usage
Use the **primary horizontal logo** in:
- product header
- auth screen
- internal documentation
- product share surfaces on light backgrounds

Use the **standalone mark** in:
- compact nav contexts
- tenant/product switcher contexts
- app icon and favicon derivations
- cases where the product name is already nearby
