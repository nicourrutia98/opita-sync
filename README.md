# Opita Sync

## Proposito

Espacio de trabajo inicial para definir y evolucionar `Opita Sync`, una plataforma empresarial de orquestacion operativa por lenguaje natural.

## Estado actual

Este proyecto nace desde una fase de definicion de producto y modelo de negocio. Todavia no contiene implementacion tecnica ni codigo de runtime propio.
