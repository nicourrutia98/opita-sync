# Module 10. Reporting de Valor y Adopcion

## Purpose

Demonstrate operational value, adoption, and positive business effects beyond simple time savings.

## Scope

- Operational metrics
- Adoption metrics
- Positive action tracking
- Friction reduction indicators
- Capability and tenant views

## Primary Actors

- Sponsor
- Supervisor
- Admin tenant
- Operador Opita Code

## Key Inputs and Outputs

- Inputs: case events, audit events, billing attribution, capability usage, operational outcomes
- Outputs: dashboards, period views, capability views, adoption summaries

## Core Flows

1. Aggregate governed operational and usage events.
2. Compute tenant and capability metrics.
3. Present dashboard views according to role.

## Business Rules

- Value is not measured only by time saved.
- Positive operational actions must be visible.
- Reporting must remain separate from low-level technical telemetry.

## Dependencies

- Module 02. Casos y Solicitudes
- Module 03. Bitacora Operativa
- Module 05. Catalogo de Capacidades
- Module 11. Billing y Consumo
- Module 09. Auditoria y Trazabilidad

## Acceptance Focus

- Basic tenant dashboard
- Period and capability views
- Adoption and positive-action traceability

## Open Gaps

- Final executive KPI set by sector or domain
