# Frontend Branding

## Runtime Rule

- Use `Flow Grid v3` primary lockup in the product header and other full-width system surfaces.
- Use the `Flow Grid v3` standalone mark only in compact identity contexts such as favicon, switchers, and small status chips.
- Keep branding out of data-heavy surfaces such as forms, tables, case cards, and operational lists.
- Do not use gradients, glow, glass, or decorative overlays behind the lockup.

## Proposed App Icon

- Source file: `public/brand/opita-sync-app-icon.svg`
- Intent: a clean launcher-safe icon built from the same governed-grid logic without reusing a mock screen or paid design source.
- Shape: rounded square tile with a 2x2 operational grid, one active teal node, two structural dark nodes, and one outlined support node.
- Use this icon as the favicon and as the export source for future iOS and Android launcher assets.

## Theme Pairing

- Light theme uses the color lockup and the proposed icon on neutral product surfaces.
- Dark theme swaps to the dark Flow Grid assets while preserving the same semantic token map.
- The app icon keeps its own contrast envelope and does not need a separate dark launcher redesign unless store rules require it later.
