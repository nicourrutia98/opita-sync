# Opita Sync Tenant Accessibility Baseline

## Propósito
Definir defaults accesibles del tenant sin permitir combinaciones por debajo del baseline de plataforma.

## Rol / actor
tenant-admin

## Regiones
- Controles de baseline
- Preview
- Validation rail

## Jerarquía
- Mínimos de plataforma
- Defaults configurables
- Preview
- Validación

## Componentes clave
- Bloqueos de labels/foco
- Texto base
- Espaciado
- Contraste reforzado
- Reducir movimiento

## Estados clave
- Válido
- Inválido por contraste
- Inválido por combinación no permitida
- Publicado
- Solo lectura pendiente backend

## Notas desktop
- Editor central + rail derecha de validación

## Notas mobile
- Controls apilados
- Preview resumido
- CTA sticky Guardar cambios

## Notas accessibility
- Las opciones inseguras se bloquean antes de guardar
- Preview con componentes reales
- Estados siempre con texto

## Decisiones visuales críticas
- Sin theming libre
- Continuidad total con settings
- Teal para acciones, no para success semántico
