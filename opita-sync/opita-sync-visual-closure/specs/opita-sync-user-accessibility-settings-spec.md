# Opita Sync User Accessibility Settings

## Propósito
Permitir overrides personales accesibles sin bajar del baseline del tenant o la plataforma.

## Rol / actor
user

## Regiones
- Summary de baseline activo
- Controles personales
- Preview en vivo
- Save bar

## Jerarquía
- Estado heredado vs personalizado
- Preview
- Controles
- Guardar o resetear

## Componentes clave
- Selector de tamaño de texto
- Espaciado
- Contraste reforzado
- Reducir movimiento
- Foco reforzado

## Estados clave
- Heredado
- Personalizado
- Cambios sin guardar
- Guardado
- Solo lectura pendiente backend

## Notas desktop
- 2 columnas: controles + preview

## Notas mobile
- Preview arriba
- Controles apilados
- CTA sticky Guardar cambios

## Notas accessibility
- La pantalla es accesible por diseño
- Labels persistentes no se desactivan
- Preview usable con text scaling

## Decisiones visuales críticas
- Preview usa tokens reales
- Blue solo para foco
- Teal solo para CTA y acento operativo
