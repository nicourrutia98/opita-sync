# Opita Sync Tenant Theme Baseline

## Propósito
Exponer la personalización controlada del tenant sin white-label ni drift de marca.

## Rol / actor
tenant-admin

## Regiones
- Identidad del tenant
- Selector de preset
- Preview de shell
- Governance rail

## Jerarquía
- Qué sí cambia
- Preview
- Qué permanece bloqueado
- Guardar

## Componentes clave
- Nombre visible del tenant
- Logo secundario
- Preset aprobado
- Preview de shell
- Reglas bloqueadas

## Estados clave
- Preset actual
- Sin logo secundario
- Logo inválido
- Cambios sin guardar
- Publicado

## Notas desktop
- Preview grande + governance rail

## Notas mobile
- Preview compacto por cards
- Edición por bloques
- CTA sticky Guardar cambios

## Notas accessibility
- El tenant no puede reemplazar la marca principal
- Contraste y foco permanecen bloqueados
- Preview con texto real

## Decisiones visuales críticas
- Teal-first product shell
- Tenant branding secundario
- Mismo shell y superficies del resto del producto
