# Opita Sync Tenant Admin Settings

## Propósito
Configurar defaults y reglas visibles del tenant sin romper plataforma, marca ni baseline visual.

## Rol / actor
tenant-admin

## Regiones
- Left nav de secciones
- Main config con formularios, matrices y previews
- Impact / publish rail

## Jerarquía
- Sección activa
- Herencia de plataforma vs configuración del tenant
- Cambios pendientes
- Publicación

## Componentes clave
- Matriz de permisos
- Badges Heredado / Configurable
- Preview de shell
- Publish rail
- Validation summary

## Estados clave
- Sin cambios
- Draft
- Validación pendiente
- Publicado
- Solo lectura pendiente backend

## Notas desktop
- Left nav persistente
- Rail de publicación separado de la edición

## Notas mobile
- Task-first
- Section list + focused editor
- CTA sticky Guardar / Publicar

## Notas accessibility
- Labels persistentes
- Summary de errores enlazable
- Alternativa apilada para matrices en mobile

## Decisiones visuales críticas
- Admin/settings comparten el mismo shell del producto
- Sin dashboard paralelo
- Teal-first en acciones primarias
