# context-core

## Objetivo

Servir como base centralizada de contexto local para `traductor-tecnico`, `spec-hub` y futuras skills, minimizando tokens sin perder calidad de respuesta.

## Qué almacena

- manifiesto del proyecto
- decisiones de arquitectura
- cards de requerimientos
- cards de dominio
- estado de sesiones cortas
- referencias a specs y revisiones

## Contrato operativo

`spec-hub` usa esta carpeta como storage persistente local. Los artefactos viven como JSON o Markdown versionables y consultables por full-text simple.
