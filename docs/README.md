## Regla de uso

- overview explica que es Opita Sync y cual es su alcance ejecutivo;
- explanation fija principios y decisiones no negociables;
- reference fija reglas concretas y especificaciones base;
- compliance fija reglas de datos, retencion y limites de reutilizacion;
- cualquier documento nuevo debe declarar estado, alcance y documentos relacionados;
- cualquier documento nuevo debe validarse con `validate-operational-logic` antes de tratarse como fuente aprobada.
