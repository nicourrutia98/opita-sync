# Frontend Image Prompts for ChatGPT

Use these prompts in ChatGPT image generation to create the remaining visual assets for `Opita Sync`.

## Global Instructions

Apply these rules to every prompt:

- brand direction: `Operational Clarity`
- personality: governed, precise, trustworthy, restrained
- category: enterprise operational platform
- avoid playful chatbot aesthetics
- avoid marketing gradients
- avoid glow effects
- avoid purple-dominant palettes
- keep shapes simple and legible
- optimize for light neutral operational surfaces
- preserve strong contrast and readability
- output must feel usable in a real software product

Canonical palette:

- primary teal: `#0F766E`
- dark teal: `#115E59`
- text primary: `#111827`
- text secondary: `#334155`
- muted text: `#64748B`
- border: `#CBD5E1`
- app background: `#F7F8FA`
- panel background: `#FFFFFF`
- success: `#166534`
- warning: `#A16207`
- error: `#B91C1C`
- info: `#1D4ED8`
- focus: `#0F62FE`

Typography direction:

- professional humanist sans feel
- clean, operational, enterprise-safe
- no futuristic gimmicks
- no playful rounded startup look

## Master Prompt

```text
Create a clean enterprise-grade visual asset system for a product called "Opita Sync" by Opita Coders. The product is a governed operational orchestration platform, not a generic chatbot. The visual direction is "Operational Clarity": precise, trustworthy, restrained, highly legible, accessibility-safe, and appropriate for operational software. Use a teal and slate palette with light neutral backgrounds. Avoid gradients, glows, purple SaaS aesthetics, mascots, cartoon styles, and playful bot visuals. Prefer simple geometry, strong legibility, and calm, premium restraint. All outputs should look crisp on white or light neutral UI surfaces and work in a real production app.
```

## Prompt 1. Primary Logo

```text
Using the following brand direction, generate a primary logo for "Opita Sync":

Brand direction: Operational Clarity. Enterprise operational platform. Governed, precise, trustworthy, restrained. Light neutral product surfaces. Teal and slate palette. No gradients, no glow, no mascot, no chatbot imagery, no futuristic gimmicks.

Design a horizontal primary logo for the product name "Opita Sync". The mark should feel software-native, operational, and modern without being trendy. It should communicate orchestration, flow control, clarity, and structure. Use simple geometric forms if a subtle symbol is included, but keep the result minimal and scalable. The logo must remain legible in a web app header and auth screen. Prefer a refined wordmark-first solution. Show on a very light neutral background. High contrast, crisp edges, accessible color use.

Deliver a few distinct directions, not tiny variations of the same logo.
```

## Prompt 2. Monochrome Logo

```text
Create monochrome versions of the "Opita Sync" logo for software product usage. Use the approved visual direction: Operational Clarity, enterprise-safe, restrained, precise, no decorative effects. Generate:

1. dark-on-light monochrome version
2. light-on-dark monochrome version

The logo must stay highly legible at small sizes, in navigation bars, loading states, exports, and documentation. Preserve simple forms, clean spacing, and a premium operational feel. Avoid thin fragile strokes and avoid ornate typography. Show both monochrome variants clearly on appropriate neutral backgrounds.
```

## Prompt 3. Reduced Mark / Isotype

```text
Design a reduced brand mark for "Opita Sync" that can be used as an app icon base, favicon base, and compact brand symbol. The mark should suggest orchestration, structured flow, governed movement, or connected operational states without looking like a chat bubble, robot, spark, or generic AI symbol.

Brand direction: Operational Clarity. Enterprise operational platform. Teal/slate palette. Minimal, geometric, accessible, highly legible at small sizes. It must still work at very small favicon scale. Avoid visual clutter, internal tiny details, excessive strokes, and decorative tricks.

Generate several distinct reduced-mark options on light neutral backgrounds.
```

## Prompt 4. App Launcher Icon

```text
Create an app launcher icon for "Opita Sync" using the approved reduced mark direction. The icon should feel premium, operational, and software-native. It must read clearly on mobile home screens and desktop launchers. Use a restrained teal/slate palette, simple geometry, high contrast, and generous safe padding. No gradients, no glow, no 3D glass, no mascot, no chat bubble cliché.

Show the icon as:
1. a square app icon concept
2. a rounded-square app icon concept
3. a simplified adaptive-icon-ready composition

Use a light or softly tinted neutral background that keeps the mark readable. Keep the result strong at small sizes.
```

## Prompt 5. Favicon

```text
Design favicon-ready concepts for "Opita Sync" based on the reduced mark or the letters "OS" only if absolutely necessary. The favicon must remain identifiable at 16x16 and 32x32 sizes. Use extremely simple geometry, strong contrast, no tiny internal details, no decorative strokes, and no text beyond what is strictly necessary. The result must feel like a serious enterprise product, not a playful startup or AI toy.

Show concepts on white and light neutral backgrounds. Prioritize clarity over expressiveness.
```

## Prompt 6. Optional Empty-State Illustration Set

```text
Create a very restrained empty-state illustration style for "Opita Sync" for optional use only. The product is an enterprise operational platform with a chat-first workspace. The illustration style must support operational clarity, not dominate the interface.

Requirements:
- minimal line-based or flat geometric style
- no characters, mascots, or cartoon scenes
- no decorative gradients
- low visual noise
- works beside enterprise copy and form-driven workflows
- suitable for states like: no conversations yet, no visible cases, no members yet

Use the teal/slate palette very sparingly on light neutral backgrounds. The result should feel calm, precise, and secondary to the UI.
```

## Prompt 7. Optional Subtle Background Pattern

```text
Design a subtle branded background or pattern system for "Opita Sync" that could be used very lightly in auth or onboarding surfaces. The product is an enterprise operational platform with a restrained visual direction called Operational Clarity.

The pattern should be abstract, geometric, low-contrast, and quiet. It may suggest flow, orchestration, structured paths, or connected states, but must never distract from text, forms, or accessibility. No gradients, no neon, no excessive density, no visual noise.

Show several low-contrast options on light neutral surfaces.
```

## Prompt 8. Social / Share Image

```text
Create a social/share image concept for "Opita Sync" by Opita Coders. The product is a governed operational orchestration platform. The visual should feel premium, enterprise-safe, restrained, and operational. Use a light neutral background, teal/slate palette, strong typography hierarchy, and subtle geometric structure that suggests orchestration and clarity.

Avoid marketing hype styling, chatbot clichés, glowing AI motifs, and decorative gradients. The result should feel like serious B2B software.
```

## Iteration Prompt: Refine Toward Production

Use this after generating an asset you like:

```text
Refine this concept toward production readiness. Keep the same core direction, but improve small-size legibility, spacing balance, contrast, and geometric simplicity. Remove any decorative detail that would hurt favicon, app icon, or UI-header usage. Keep it enterprise-safe, restrained, and operational.
```

## Iteration Prompt: Make It More Minimal

```text
Make this asset more minimal, more structured, and more suitable for an enterprise operational platform. Reduce unnecessary detail, increase clarity, improve small-size recognizability, and keep the visual language calm and precise.
```

## Iteration Prompt: Export-Friendly Variant

```text
Create an export-friendly variant of this asset with cleaner silhouette, stronger contrast, simpler geometry, and safer spacing for SVG, PNG, app icon, and favicon usage. Prioritize production usability over expressiveness.
```

## Selection Criteria

Choose outputs that satisfy all of these:

- looks credible in enterprise software
- readable on light neutral UI surfaces
- works at small size
- not dependent on gradients or effects
- not confused with a chatbot brand
- compatible with teal/slate accessible palette
- simple enough to export as SVG and PNG
