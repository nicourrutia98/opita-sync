# Iconography Specification

## Purpose

Define the minimum icon inventory and usage rules.

## Recommended baseline

- use one coherent outline icon family with strong legibility at small sizes
- pair icons with text for all critical actions
- never rely on icons alone for status or destructive actions

## Required icons

- sign in
- invite
- conversation
- case
- status
- add update
- draft
- settings
- members
- accessibility
- warning
- blocked
- retry
- success
- audit
- trace
