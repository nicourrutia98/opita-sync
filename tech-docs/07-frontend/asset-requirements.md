# Asset Requirements

## Purpose

List the inputs required before final visual implementation.

## Required brand inputs

- primary logo
- monochrome logo
- reduced logo mark
- app launcher icon
- favicon or web app icon
- approved app short name

## Required product inputs

- support contact text
- legal footer text
- tenant display naming rules
- avatar policy
- status label glossary

## Optional brand inputs

- onboarding illustration set
- empty-state illustration set
- branded pattern or background system
- marketing screenshots for help surfaces

## Safe placeholders allowed in v1

- initials-based avatars
- no-illustration empty states
- neutral favicon with product initials
- neutral accessible theme from `theme-baseline.json`
