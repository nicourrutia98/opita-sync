# Mockup Generation Brief

## Purpose

Provide a single canonical brief for a downstream UI generation agent.

## Product summary

Opita Sync is a governed operational orchestration platform with a chat-first workspace. The interface must center the conversation thread while exposing case state, guided forms, and role-aware actions around it.

## Required design direction

- operational
- premium but restrained
- chat-first
- highly legible
- accessibility-safe
- mobile-capable from day one

## Required surfaces

- auth and invite
- requester workspace
- technician workspace
- supervisor workspace
- tenant-admin settings
- user accessibility settings
- tenant accessibility baseline editor

## Forbidden patterns

- generic chatbot landing page
- dashboard-only home with hidden chat
- dark aesthetic that reduces contrast
- icon-only critical controls
- color-only status communication
