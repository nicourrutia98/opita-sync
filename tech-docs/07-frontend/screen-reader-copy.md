# Screen Reader Copy

## Purpose

Provide baseline announcements and hidden labels for dynamic UI.

## Live announcements

- `New assistant response available`
- `Case created successfully`
- `Status updated`
- `Draft generated`
- `Permission denied for this action`
- `Changes saved`
- `Connection lost. Working offline where possible`
- `Connection restored`

## Hidden labels

- composer send button: `Send message`
- conversation rail toggle: `Open conversation navigation`
- case detail toggle: `Open case details`
- close sheet: `Close panel`
- retry action: `Retry last action`
