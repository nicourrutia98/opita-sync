# UI Copy Baseline

## Purpose

Provide consistent baseline copy for operational UI states.

## Tone

- direct
- operational
- non-promotional
- explicit about permission and recovery

## Core labels

- `New conversation`
- `Current cases`
- `Track status`
- `Add update`
- `Generate draft`
- `Tenant settings`
- `Accessibility`
- `Members`
- `Retry`
- `Save changes`

## Baseline system messages

- `We need a little more information to complete this request.`
- `This action is blocked by your current role or tenant rules.`
- `Your changes were saved.`
- `This update could not be completed. Review the details and try again.`
- `This draft is based on the current case context and tenant rules.`
- `No visible cases match your current scope.`
