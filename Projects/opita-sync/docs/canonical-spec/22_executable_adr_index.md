# 22. Executable ADR Index

## Purpose
List the critical ADRs that directly govern implementation order and non-negotiable technical behavior.

## ADRs
- ADR-001 ? Governed execution, not free agent loop
- ADR-002 ? Explicit execution contract boundary
- ADR-003 ? Policy validation before execution compilation
- ADR-004 ? Separate permission decisions
- ADR-005 ? Central connector governance
- ADR-006 ? Approvals are runtime state transitions
- ADR-007 ? Output control separate from execution success
- ADR-008 ? Governance and Settings stay separate
- ADR-009 ? Durable runtime required
- ADR-010 ? Provider-agnostic governance

## Use rule
When implementation tradeoffs arise, these ADRs outrank convenience and default framework behavior.
